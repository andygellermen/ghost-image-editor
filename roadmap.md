## Cropper v1

- Klassisches DOM-basiertes API
- `new Cropper(image, options)` 
- Sehr stabil, lange im Einsatz
- Riesige Community
- Unzählige Beispiele

## Cropper v2

- Modularer aufgebaut
- Teilweise modernisierte API
- Interne Struktur überarbeitet
- Noch nicht so weit verbreitet
- Weniger Legacy-Beispiele

## Wichtig:
v2 ist nicht zwingend „besser“ für jedes Projekt — sondern moderner.

## Was ist das Ziel dieses Plugins?

- maximale Stabilität?
- lange Wartbarkeit?
- geringe Breaking-Changes?
- Open-Source für Ghost-Nutzer?
